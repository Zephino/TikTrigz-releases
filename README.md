# TikTrigz downloads

Download the newest **TikTrigz** for Windows from **[Releases](../../releases/latest)**: the file `TikTrigz-x.y.z-win-x64.exe`.

1. Run the `.exe` and follow the installer.
2. Windows may show a SmartScreen warning because the installer is not code-signed: click **More info → Run anyway**.

**Updating:** TikTrigz updates itself. When a new version is out, the app shows *"Update ready — Restart to update"*.
You can also install a newer `.exe` over the old one at any time. Your settings are kept.

Most features need a TikTrigz Pro key.
